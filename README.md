# 📚 StudyStride

A responsive study task planner built with vanilla JavaScript, HTML5, and CSS.

## Features
- Add, edit, toggle, and delete study tasks
- Automatic sorting by priority (High, Medium, Low)
- Real-time progress bar and task statistics
- Light and Dark mode toggle
- LocalStorage support to keep data across sessions

## How to Run
Open `task1.html` in any web browser.
